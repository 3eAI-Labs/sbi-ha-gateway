## How to accept

Open your pull request as normal. A bot will comment on it and ask you to accept this agreement by
posting exactly this sentence as a pull request comment:

```
I have read the CLA Document and I hereby sign the CLA
```

The bot records your GitHub username, the pull request and the date in a signature file held in a
separate 3eAI Labs repository, and the pull request status check turns green. You do this once; the
record covers your later pull requests too.

If a correction is needed after you have accepted, comment `recheck` on the pull request.
